Product direction

Axio is a native, local-first workspace for running, steering, and reviewing coding agents.

The target experience

  1. Open a repository.
  2. Launch one or more coding agents.
  3. Give them deliberate worktree and task boundaries.
  4. Observe progress, questions, commands, and failures in one place.
  5. Review files and diffs, redirect work, and merge the result.
  6. Reopen Axio without losing the workspace.

What 1.0 means

Version 1.0 is the stable product contract, not a promise to include every integration. The CLI, persistence and migrations, connector schema, orchestration protocol, release artifacts, and supported workspace behavior must be clear and dependable.

What is intentionally absent

The foundation does not require a hosted account, billing system, marketplace economy, or a replacement native LLM agent loop. Those systems should not define the local product.

Versioned technical documentation lives with the code.

The public website presents it, while the canonical contract remains reviewable beside the Rust implementation.
